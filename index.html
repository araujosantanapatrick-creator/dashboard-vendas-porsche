Perguntas de negócio

1. Qual modelo gera mais receita?

Compara a soma dos preços por modelo para destacar os que mais contribuem para o faturamento.

2. Quais cidades têm mais vendas?

Mostra as cidades com maior número de registros de venda no recorte selecionado.

3. Qual método de pagamento é mais utilizado?

Compara a quantidade de vendas por método de pagamento.

Sobre os dados: a dashboard utiliza as colunas sanitizadas da planilha. Os registros cuja data aparece como INVALID continuam incluídos nos totais, pois a data não é usada como filtro. Os valores representam os dados da base de treinamento.
