# Dashboard de Vendas Porsche

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de transformar uma planilha de vendas da Porsche em uma dashboard interativa, simples e fácil de consultar.

A dashboard foi criada em HTML e JavaScript, com gráficos e filtros que ajudam a visualizar as informações das vendas.

## Objetivo

Facilitar a análise dos dados e permitir uma compreensão melhor dos resultados comerciais apresentados na planilha.

## Perguntas de negócio

A dashboard busca responder a três perguntas:

1. **Quais modelos da Porsche geram mais receita?**  
   Permite comparar o faturamento dos modelos e identificar os que mais contribuem para o resultado.

2. **Quais cidades apresentam mais vendas?**  
   Ajuda a identificar as cidades com maior volume de vendas.

3. **Qual é o método de pagamento mais utilizado?**  
   Mostra a distribuição das vendas de acordo com a forma de pagamento.

## Indicadores e filtros

A dashboard apresenta indicadores de total de vendas, receita e ticket médio, além de filtros para consultar os dados por modelo, cidade, ano e método de pagamento.

## Tratamento dos dados

Foi utilizada a planilha sanitizada disponibilizada no desafio. Os campos sanitizados foram priorizados para a análise, e os valores de preço e ano foram tratados para permitir os cálculos e a construção dos gráficos.

Os registros com data inválida foram mantidos na base, sem atribuir datas que não estavam disponíveis.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- Chart.js
- GitHub Pages

## Desenvolvimento

A dashboard foi construída com auxílio do ChatGPT, utilizando instruções em linguagem natural para definir os indicadores, os gráficos, os filtros e o visual da página.

Durante o desenvolvimento, a proposta foi manter o projeto simples, funcional e fácil de entender.
